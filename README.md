# Portfolio Website (CSE AI/ML Student)

A modern, unique, and professional portfolio website built with plain HTML, CSS, and JavaScript.

## Files

- index.html: Structure and sections
- styles.css: Theme, layout, responsive design, animation
- data.js: All personal content (edit this first)
- script.js: Rendering and interactions

## How to Edit Quickly

1. Open data.js.
2. Update:
   - Name, role, summary, resume URL
   - Skills
   - Projects (title, summary, tech, links)
   - Experience and certifications
   - Education and contact links
3. Save and reload.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Go to Vercel and click Add New Project.
3. Import the repository.
4. Framework preset: Other.
5. Build command: leave empty.
6. Output directory: leave empty.
7. Deploy.

## Content Checklist (Must Have)

- Professional photo (optional but recommended)
- Strong one-line headline (who you are + what you do)
- About section in 4-6 lines
- 3-5 best projects with outcomes and links
- Skills grouped by category
- Resume (PDF link)
- Education details + CGPA
- Internship/experience details
- Certifications (relevant and recent)
- GitHub and LinkedIn links
- Working contact email

## Student-Specific Tips

- Keep project descriptions outcome-oriented (what problem, what result).
- Show both software and AI/ML projects for balanced profile.
- Include 1 deployed project and 1 repository with clean README.
- Use consistent naming, grammar, and formatting.
